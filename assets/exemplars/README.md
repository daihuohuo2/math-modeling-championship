# 获奖论文基准（Exemplars）

把搜集到的获奖论文 PDF 放进本目录（只读参考，**绝不进入提交包**），命名建议
`竞赛_年份_题号_奖次.pdf`，例如 `CUMCM_2024_A_国一.pdf`、`MCM_2025_B_O.pdf`。

## 两个使用时机

1. **Stage 8 写作前**：读一遍下方共性清单，对照本队大纲核对结构覆盖；
2. **E13/E14/E15 评分前**：把成稿的摘要页、图表密集页与获奖论文对应页并排比对后再打分，用具体基准压住 AI 自评偏松。

## 获奖论文共性清单

以下条目来自 COMAP 官方评审标准、O 奖论文共性总结与 2026 策联杯获奖卷的实评对比，是本 Skill 论文规范的证据来源：

- **摘要/Summary Sheet**：一页以内，独立可读；先一句路线图，再按问给"方法—关键处理—量化结果—结论"，以决策收尾；核心数字带区间；显式披露关键局限。
- **假设**：少而精（约 5–8 条），每条有理由并挂钩模型用途；没有凑数的空假设。
- **模型**：推导自足（derived, not just cited），外借方法只作组件引用；方法与问题结构匹配，不堆砌流行算法。
- **结果**：具体数值 + 误差/区间；有灵敏度、稳健性和失败边界分析；负结果如实报告并说明决策如何降级。
- **图表**：专业、自足、克制；每图正文有引用；灰度可读；流程图对应真实流程。
- **写作**：术语唯一、推导连贯、有 Strengths & Weaknesses 类自评章节；引用规范、双向对应。
- **合规**：匿名、页数、指定交付物（memo/letter/表格）、AI 使用声明逐项满足。
