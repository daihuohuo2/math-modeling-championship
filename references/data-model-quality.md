# 数据、模型与验证质量

## 数据台账与外部数据闸门

为每个文件、工作表和网页记录来源、日期、许可、SHA-256、字段、单位、缺失、异常、时间范围、物理对象及是否进入训练、调参或测试。

外部信息分类为 `background`、`covariate`、`training_label`、`ground_truth` 或 `benchmark_only`。题面未提供的训练标签或真实答案默认不能进入主解。确需使用时，先解释它如何改变任务、取得用户决定、保留赛题数据主线、在摘要/方法/结果显著披露，并做有无外部数据的消融对比。

可能包含目标答案、隐藏标签或未来信息的文件先进入强制状态机：`quarantined → classified → rule_checked → user_authorized → dual_track_only`。前四步未全部留证前，不得把该文件加载进主预处理、特征选择、调参或性能评估。官方规则禁止时停在 `rule_checked` 并记录 `rejected`；用户一句“能提高就用”不替代对任务变化、泄漏风险和披露方式的知情决定。每条 `quarantined_inputs` 记录至少包含路径/哈希、类别、`rule_checked`、`user_authorized`、`mainline_excluded` 和 `status`；最终状态只允许 `rejected` 或 `dual_track_only`。

## 独立实验单位与泄漏

先画层级：`对象 → 批次/协议 → 时间序列/空间段 → 重复测量/窗口 → 行`。以最上层会共享信息的物理实体作为切分组。特别检查：

- 同一对象的滑动窗口跨越训练和测试；
- 续接实验、重复采样或同批次伪装成不同 ID；
- 标准化、插值、特征选择在全数据上先拟合；
- 未来信息、终点或人工注释进入特征；
- 调参与汇报复用同一折。

## 预处理

平滑、去噪、插值、异常处理、归一化、降维和特征工程都保存参数依据、拟合范围、处理前后图和结论敏感性。不得只因曲线更顺或指标更高选参数。

对截尾或删失终点，优先报告删失状态、区间估计、受限均值或生存/可靠性口径；不得用便利的外部终点把未知值补成真值。

## 模型选择与验证

每问先建可解释强基线，再比较至多两个模型族。候选表包含目标函数、状态变量、约束、数据需求、可识别性、代价、失败风险、验证方式和论文解释成本。

复杂模型须在同一切分和指标下稳定优于基线，且增益在不同种子、分组或合理参数扰动下仍存在；否则降为探索或删除。

- 选择模型、超参数、时间窗或特征并汇报性能时，用嵌套交叉验证或独立验证集；
- 时间数据用滚动/前向切分，空间数据按区域留出，多对象数据按对象/批次分组；
- 报告中心趋势、离散程度和置信区间，不只给单次最好值；
- 做负对照、消融、边界场景、参数敏感性和误差传播；
- 区分近程预测和远程外推，远期扩大不确定性并说明支持域。

每个核心结论回答数值、比较对象、误差、成立条件、领域机制和失败后果。不要把相关性写成因果，不要把拟合优度写成预测能力。
